# ParleyLab 2.2

## Novedades
- Pestaña Bullpen.
- Pitcheo total del equipo como referencia.
- Últimos 10 juegos de cada equipo.
- Carreras anotadas y permitidas.
- Secuencia W/L.
- Últimas 5 aperturas de cada abridor.
- ERA, innings, ponches y bases por bolas del periodo reciente.

## Transparencia
MLB no siempre ofrece un endpoint público completamente separado para bullpen. Por ello, el panel explica que usa pitcheo total del equipo como referencia.

## Instalación
Reemplaza `index.html`, `styles.css`, `app.js` y `README.md` en GitHub. Vercel publicará automáticamente.

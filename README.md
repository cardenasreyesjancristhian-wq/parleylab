# ParleyLab 2.4 — Selector de mercados y constructor de parley

## Novedades

- El botón de cada partido abre directamente la pestaña **Cuotas**.
- Selección directa de Moneyline, Run Line, Over y Under.
- Momio combinado decimal y americano.
- Probabilidad implícita del boleto.
- Ganancia potencial y retorno total.
- Contador de picks en la navegación inferior.
- Eliminación individual de selecciones.
- Prevención de picks duplicados.
- Advertencia cuando hay selecciones correlacionadas del mismo partido.
- Advertencia para parlays de seis o más selecciones.
- Confirmación visual al agregar un pick.

## Instalación

Reemplaza `index.html`, `styles.css`, `app.js` y `README.md`. Conserva `api/odds.js` y la variable `ODDS_API_KEY` de Vercel.

## Importante

La probabilidad implícita procede de los momios combinados. No representa una predicción propia ni garantiza resultados.

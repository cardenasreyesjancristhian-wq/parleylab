# ParleyLab 2.1 — Actualización 2

## Novedades

- Comparación de pitchers abridores.
- ERA, WHIP, innings, ponches, bases por bolas y récord.
- Comparación de ofensivas.
- AVG, OBP, SLG, OPS, jonrones y carreras.
- Pestañas dentro de la ficha del partido:
  - Resumen
  - Abridores
  - Ofensivas
- Datos obtenidos de MLB Stats API.
- Caché temporal para reducir consultas repetidas.
- Manejo de datos faltantes sin inventar valores.
- Estados de partidos traducidos al español.
- Marcador disponible para juegos iniciados o terminados.

## Instalación

Reemplaza en tu repositorio los cuatro archivos:

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Vercel publicará automáticamente la actualización.

## Importante

Las comparaciones resaltan únicamente la mejor cifra de la métrica mostrada. No representan una probabilidad de victoria ni una recomendación automática.

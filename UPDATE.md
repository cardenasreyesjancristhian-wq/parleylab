# Cómo actualizar ParleyLab desde iPhone

Después de instalar ParleyLab 4.0:

1. Abre GitHub.
2. Reemplaza `app.js`.
3. Reemplaza `styles.css`.
4. Reemplaza `version.json`.
5. Haz `Commit changes`.
6. Espera a que Vercel publique la nueva versión.

No cambies:

- `api/odds.js`
- `ODDS_API_KEY`
- `loader.js`

Solo habrá instrucciones adicionales cuando una versión requiera una nueva API o archivo.
